# 🖥️ Guide de Téléchargement & Installation — StudyVault Desktop (Windows)

Bienvenue dans la Bêta Fermée de **StudyVault** ! Ce guide vous explique pas à pas comment installer l'application desktop officielle sur votre ordinateur Windows.

---

## 💻 Configuration Minimale Requise

- **Système d'exploitation** : Windows 10 (64-bit) ou Windows 11
- **Espace disque libre** : 50 Mo
- **Connexion Internet** : Recommandée pour la synchronisation et les mises à jour automatiques

---

## 📥 Étape 1 : Télécharger l'Installeur

Téléchargez le fichier d'installation officiel depuis le lien transmis dans votre email d'invitation bêta :
- **Fichier** : `StudyVault_1.0.0_x64_en-US.msi` (ou `StudyVault_1.0.0_x64-setup.exe`)
- **Taille** : ~10 à 15 Mo (ultra-léger grâce à la technologie Tauri)

---

## ⚙️ Étape 2 : Lancer l'Installation

1. Double-cliquez sur le fichier téléchargé `StudyVault_1.0.0_x64_en-US.msi`.
2. Si une alerte de sécurité Windows SmartScreen apparaît (*"Windows a protégé votre ordinateur"*), cliquez sur **"Informations complémentaires"** puis **"Exécuter quand même"**.
3. Suivez les étapes de l'assistant d'installation (cliquez sur *Suivant* ➔ *Installer*).
4. Une fois l'installation terminée, cochez la case **"Lancer StudyVault"** et cliquez sur **"Terminer"**.

---

## 🗝️ Étape 3 : Se Connecter & Activer la Bêta

1. Au premier lancement de l'application, la page de connexion apparaît.
2. Si vous n'avez pas encore créé de compte, cliquez sur **"Créer un compte"**.
3. Renseignez votre nom, email universitaire, mot de passe et votre **Code d'Invitation Bêta** (ex: `SV-BETA-001`).
4. Une fois connecté, le **Guide Interactif d'Onboarding** s'affiche automatiquement pour vous présenter l'ensemble des fonctionnalités en 6 étapes.

---

## 🔄 Étape 4 : Mises à Jour Automatiques

StudyVault Desktop intègre un système de mise à jour silencieuse :
- Chaque démarrage vérifie si une nouvelle version est disponible sur le serveur.
- Si une mise à jour est détectée, une notification apparaît dans l'application avec un bouton d'installation en 1 clic.
- Vous pouvez également vérifier manuellement via le menu natif : **Aide ➔ Vérifier les mises à jour**.

---

## ❓ Besoins d'Aide ou Signalement de Bugs ?

Pendant toute la durée de la Bêta Fermée, vous pouvez utiliser le bouton flottant violet **"Feedback Bêta"** situé en bas à droite de l'application pour signaler un problème ou proposer une suggestion.
